# Lordcay Portfolio - Full Stack & AI Developer

This is a professional portfolio website built with Next.js, MongoDB, and Tailwind CSS. It showcases projects across e-commerce, AI, fintech, education, and enterprise systems.

## 🚀 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Shadcn UI
- **Database:** MongoDB (with Mongoose ODM)
- **Authentication:** JWT (JSON Web Tokens)
- **Deployment:** Vercel (recommended)

## ✨ Features

- Fully responsive design with gradient UI
- Dynamic project showcase with admin panel
- Contact form with message storage
- Skills & technology grid
- Mobile-optimized navigation
- Admin dashboard for content management

## 📋 Prerequisites

- Node.js 18+ and npm/yarn/pnpm
- MongoDB Atlas account (free tier) or local MongoDB instance
